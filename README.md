Facultad de Ciencias Sociales

Programa Académico de Innovación Social

Descripción

Este proyecto fue desarrollado como parte del examen final del curso de Desarrollo Web Frontend. Consiste en una página web informativa para promocionar el Programa Académico de Innovación Social de la Facultad de Ciencias Sociales.

Durante el desarrollo se aplicaron los temas vistos en clase, como diseño responsive, Bootstrap, accesibilidad, usabilidad y validación de formularios con JavaScript.

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
